# meteroid-clients

Libraries to interact with [Meteroid's REST API](https://api.meteroid.com/api-docs/openapi.json).

| Language | Package | Folder |
|---|---|---|
| Rust | [`meteroid-rs`](https://crates.io/crates/meteroid-rs) | [`rust/`](rust) |
| TypeScript | [`@meteroid/sdk`](https://www.npmjs.com/package/@meteroid/sdk) | [`typescript/`](typescript) |
| Python | [`meteroid`](https://pypi.org/project/meteroid/) | [`python/`](python) |
| Go | `github.com/meteroid-oss/meteroid-clients/go` | [`go/`](go) |
| Java | `com.meteroid:meteroid` | [`java/`](java) |

Refer to each SDK's README for usage, and to its `api.md` for every method.

## Development

The SDKs are generated by [perseid](https://github.com/meteroid-oss/perseid) from
[`spec/openapi.json`](spec/openapi.json), as configured in [`perseid.toml`](perseid.toml).

- A change to the spec on `main` runs the `SDKs` workflow, which opens a pull request regenerating
  every SDK.
- Merging it opens a release-please pull request. Merging that one tags each changed SDK and
  publishes it.
- `npx perseid generate` regenerates the SDKs locally, `npx perseid generate --check` checks they
  match the spec.

Files marked `@generated` are rewritten on every generation. The others (manifests, READMEs,
`CHANGELOG.md`s) are yours to edit.
